# User Stories

## Story 1 - Create Account

As a customer  
I need to create an account  
So that I can access the service  

### Acceptance Criteria
- Customer can create an account
- Account data is saved successfully

---

## Story 2 - Read Account

As a customer  
I need to read my account information  
So that I can see my account details  

### Acceptance Criteria
- Customer can view account details
- Correct account data is returned

---

## Story 3 - Update Account

As a customer  
I need to update my account  
So that my information stays current  

### Acceptance Criteria
- Customer can update account information
- Updated data is saved successfully

---

## Story 4 - Delete Account

As a customer  
I need to delete my account  
So that I can remove my information  

### Acceptance Criteria
- Customer can delete account
- Account is removed successfully
