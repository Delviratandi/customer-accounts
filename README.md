# Customer Accounts Microservice

This project provides a RESTful API service for managing customer accounts using Flask.

## Features

- Create customer account
- Read customer account
- Update customer account
- Delete customer account

## Technology Stack

- Python
- Flask
- Docker
- Kubernetes
- GitHub Actions
